## Codebase Patterns
- Python venv is at `backend/.venv` — activate with `source .venv/bin/activate` from backend/
- Run tests from `backend/` directory: `python -m pytest tests/ -v`
- Typecheck: `python -m mypy app/` from backend/
- Lint: `python -m ruff check app/ tests/` from backend/
- mypy strict mode is enabled — use explicit type annotations (e.g., `dict[str, str]` not `dict`)
- Set `asyncio_default_fixture_loop_scope = "function"` in pyproject.toml to avoid pytest-asyncio deprecation warning
- Docker Compose uses `sqlite-data` named volume for SQLite persistence
- Tests use `pyyaml` to parse docker-compose.yml — it's an extra dep in the venv
- Backend port is configurable via PORT env var (default 9080)
- Config module is at `backend/app/config.py` — use `load_config()` to get `AppConfig` dataclass
- Env var overrides: PORT, MAX_AGENTS_SYSTEM, MAX_AGENTS_PER_COLUMN, REVIEW_REJECTION_THRESHOLD, AGENT_TIMEOUT_{TYPE}
- Tests that set env vars must clean up (use `patch.dict` or try/finally) to avoid leaking state between tests
- Database module is at `backend/app/database.py` — `Base`, `get_engine()`, `init_db()`, `get_session()`
- Models are in `backend/app/models.py` — import `Ticket`, `Note`, `Event`, `AgentRegistry`, `Setting`, `TicketDependency`
- Use in-memory SQLite (`sqlite+aiosqlite:///:memory:`) for test fixtures
- `init_db(engine)` creates all tables — called in FastAPI lifespan handler on startup
