## Codebase Patterns
- dolt uses `dolt version` (not `dolt --version`) — the `--version` flag is invalid for dolt
- bd (beads) installed via `CGO_ENABLED=0 go install github.com/steveyegge/beads/cmd/bd@latest`; binary lands in ~/go/bin — symlink to ~/.local/bin for PATH availability
- SQLAlchemy identity map + `expire_on_commit=False`: when a test session creates an object, commits it, then an HTTP call (different session) mutates it, the test session returns the stale cached object unless you call `session.expire(obj)` before re-querying
- `_ensure_git_repo` in worktree.py runs git init BEFORE the `try/except SubprocessError` block — tests that mock subprocess.run must pre-create `.git/` in the tmp dir to skip it (otherwise the first captured call is `git init`, not `git worktree add`)
- AppConfig uses `max_agents_per_type` (dict, per-agent) not `max_agents_per_column` (removed scalar)
